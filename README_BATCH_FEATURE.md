# Batch Management Feature

Adds a guided Batch admin workflow to the existing New AI Bot.

- Search existing migrated batches.
- Add new batches without deleting or rewriting existing business fields.
- Register a Telegram channel/group from a message link.
- Verify the bot is an administrator and can invite users.
- Optional image, description, fee, duration, timing, demo URL, payment URL.
- Demo/payment URLs remain in the existing customer embedded-link layer.
- 24-hour + 1-person access setting per batch.
- Stores a generated slash trigger for future admin/main-account access delivery.

The main-account slash-trigger delivery remains a separate interface and is intentionally not faked by the Bot API.
